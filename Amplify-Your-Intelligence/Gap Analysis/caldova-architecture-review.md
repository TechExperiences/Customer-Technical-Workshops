# Caldova architecture recommendations

Retain the senior’s three-platform layout and the existing Copilot Studio orchestration. The [decision table](README.md) distinguishes core outcomes from details that can be simplified. These recommendations supersede the earlier proposal to move the main agent into Foundry.

| Area | Minimum proposed change |
| --- | --- |
| Fabric | Keep the lakehouse, model, ontology and data agent. Add manufacturing, competitive-product and pre-qualified CMO records. Warehouse storage capacity must not be relabelled as production capacity. |
| Foundry | Keep storage, search, models and retrieval. Add the scenario’s GMP and CMO evaluation knowledge. Align tools, prompts and citations. |
| Web IQ | Show a working, tested external-evidence path. Identify approved public or clearly labelled simulated evidence for the competitor scene. |
| Work IQ | Keep the existing connections and supply the scenario’s organization and collaboration evidence. |
| Agent reuse | Demonstrate a new agent using the shared foundation. Exact agent count, separate RFP hosting, and Foundry publishing are optional fidelity choices. |
| Entry event | Replace supplier disruption with the accelerated launch and capacity question. The email entry channel can remain with an adapted prompt. |
| Governance | Preserve scoped access, protected-content exclusion and audit evidence. Exact fleet screens and private-network deployment can be shortened or deferred with matching story edits. |

The [proposed image](caldova-minimal-workshop-architecture.png) shows the fuller target before the team selects Low-priority simplifications. It is not a mandatory build list. If the team omits Oracle, extra agents, admin screens or private endpoints, revise those parts of the diagram and facilitator narrative together.

Keep the existing dashboard resource. Adapt its measures only if it will be shown as evidence for manufacturing capacity. Preserve functioning resource names and deployment steps; change names only where needed and keep tool references consistent.

AYI02 is pending the team’s decisions. No low-priority capability has been removed from the workshop by this analysis.
